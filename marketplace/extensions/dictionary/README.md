# Dictionary

`define <word>` (or `dict <word>`) lists English definitions with part of
speech and an example when there is one. Enter copies the definition.

Press `Tab` on any row (or on the "Dictionary" row after typing just `define`)
to enter the Dictionary context: the input becomes a word search and every
keystroke looks the typed word up. `Esc` leaves it.

Data comes from [dictionaryapi.dev](https://dictionaryapi.dev).

Permissions: `network:api.dictionaryapi.dev`, `clipboard.write`.
