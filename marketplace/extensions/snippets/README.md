# Snippets

- `sn` lists your snippets, `sn <words>` filters by name and text.
- `sn add <name> = <text>` saves a snippet (same name replaces it).
- Enter copies a snippet. The actions menu (Tab) deletes it.

Snippets are stored in the extension's local storage (1 MiB quota). Nothing
leaves your machine.

Permissions: `clipboard.write` (storage needs no permission).
