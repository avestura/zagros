# Weather

`weather <place>` (or `wx <place>`) shows current conditions and a three-day
forecast from [wttr.in](https://wttr.in). With no place it uses the default
location setting; if that is empty wttr.in guesses from your IP address.

Settings: units (metric or imperial) and default location.

Permissions: `network:wttr.in`, `open`, `clipboard.write`.
